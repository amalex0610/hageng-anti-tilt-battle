# 💅 優雅主播不破防：哈耿的精緻日常 (Hageng Streamer Tilt Simulator)

> **「今天絕對不破防！做一個溫柔優雅的氣質技術台……到底是在靠杯三小啊！」**

## 📖 遊戲簡介 (Introduction)

《優雅主播不破防：哈耿的精緻日常》是一款以知名實況主「哈耿」為靈感設計的**圖奇實況破防生存 × 彈幕節奏辨識單檔網頁遊戲**。

開台之初，主播立誓維持優雅知性、溫柔甜美的技術台形象。然而，聊天室湧入的除了熱情粉絲的斗內讚美，還有大量無情的釣魚酸民、反串怪與挑釁怪。身為主控者，你必須在雙軌即時滾動的彈幕狂潮中精準辨別，即時吸收愛心死守理智線，並手起刀落 BAN 掉所有惡質黑粉。一旦破防度達 100%，主播將會憤怒拔線關台，本月圖奇收益當場歸零！

遊戲採用直覺的**雙軌判定機制**，進入左右判定圈時進行打擊：

| 操作動作 | 目標彈幕 | 鍵盤快捷鍵 | 滑鼠 / 觸控操作 | 命中效果 |
| :--- | :--- | :--- | :--- | :--- |
| **吸收愛心** | ❤️ 粉紅正向彈幕 / 乾爹斗內 | `J` / `Z` / `←` 方向鍵 | 點擊左側「吸收愛心」按鈕 | 降低破防值、增加人氣積分、觀眾數上升 |
| **封鎖 BAN 人** | 🚫 綠色黑粉釣魚 / 挑釁彈幕 | `K` / `X` / `→` 方向鍵 | 點擊右側「封鎖黑粉」按鈕 | 成功消音黑粉、積累 Combo、維持開台時間 |

> ⚠️ **失誤懲罰**：漏看黑粉未及時 BAN 人將直接增加 **+20% 破防值**，並觸發視訊鏡頭劇烈震動與主播暴躁回嗆！

## 🌟 遊戲核心特色 (Key Features)

### 1. 💢 四階段情緒表情包與破防系統
主播視訊鏡頭（Webcam）將根據即時破防度動態切換：
* **Stage 0 (0% ~ 69%) - 優雅營業**：知性優雅微笑，努力維繫溫柔氣質形象。
* **Stage 1 (70% ~ 89%) - 抽搐喝水**：眼角抽搐、狂灌礦泉水深呼吸，邊框閃爍警示黃光。
* **Stage 2 (90% ~ 99%) - 暴怒桌咚**：理智瀕臨崩潰、鏡頭劇烈晃動，血怒紅光籠罩整個實況台。
* **Stage 3 (100%) - 拔線關台**：拍桌暴怒斷線，畫面切入「本月圖奇收益已歸零」結算畫面。

### 2. 🎙️ 廣播級語音閃避 (Audio Ducking) 與獨立音量平衡
* **獨立音量控制**：背景音樂 (BGM) 與經典台詞語音 (Voice) 分開獨立滑桿調節（預設 BGM 45%、Voice 100%）。
* **廣播級語音閃避**：當主播觸發經典台詞（「去你媽的！」、「踢爆你的骨灰罈！」、「到底是在靠杯三小啊！」）時，BGM 將在毫秒內**自動壓低至 20%**，確保人聲清晰震撼；台詞播畢後平滑漸強恢復。
* **常駐快捷調音盤**：遊戲進行中隨時可點開頂部「🎛️ 音量」選單，即時微調、檢視閃避狀態或一鍵靜音。

### 3. 📷 表情包與封面照片細緻調整（方案 A）
* **全方位自訂**：首頁圓形封面美照與 4 階段情緒視訊表情包皆支援自訂上傳。
* **縮放與畫面平移**：
  * **等比例縮放 (Zoom)**：支援 50%～200% 平滑縮放。
  * **顯示模式切換**：自由選擇「裁切填滿 (Cover)」或「完整顯示 (Contain)」。
  * **拖曳調整中心位置**：直接在預覽框內按住滑鼠或觸控拖曳圖片焦點，亦可透過 X / Y 數值滑桿微調。
  * **單項重設與本機記憶**：所有調整參數與圖片永久儲存於瀏覽器 `localStorage`。

### 4. 🎵 三段式純前端即時合成音訊 (Web Audio API)
完全無需下載任何龐大外部 MP3 音檔，由瀏覽器原生振盪器即時演奏：
* **首頁**：治癒系八音盒音樂 (Sweet Kawaii Music Box)。
* **實況中**：狂暴 808 重低音陷阱節奏 (Aggressive Trap / Sub-bass)。
* **結算時**：詼諧滑稽卡通管樂 (Comical Cartoon Tuba Bounce)，以走音低音號與卡通木魚點綴「大翻車」的諷刺喜感。
* *（亦支援上傳個人喜愛的自訂 BGM 與哈耿原聲音檔）*

### 5. 🏆 實況抗壓名人堂 (Leaderboard)
* 自動記錄開台生存時間、愛心數、BAN 人數、最高 Combo 與總積分。
* 根據表現結算五大抗壓稱號：從「極度玻璃心主播」到「抗破防神級宗師」！

## 🛠️ 技術架構 (Tech Stack)

* **架構**：單一 HTML 檔案 (`index.html`)，內嵌完整 HTML5 結構、CSS3 現代自適應樣式與 Vanilla ES6+ 物件導向邏輯。
* **音訊引擎**：原生 Web Audio API，包含 GainNode 動態增益控制器、BiquadFilterNode 多重濾波器、雙向漸層排程與 AudioContext 生命週期管理。
* **語音備援**：支援 Web Speech API (`SpeechSynthesis`) 雙聲道模擬，無自訂音檔時自動調用繁體中文女聲回嗆。
* **資料儲存**：瀏覽器 `localStorage` 持久化儲存圖片 Base64、調音配置與天梯榜單。
