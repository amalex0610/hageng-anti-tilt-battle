# 💥《哈耿的抗破防大作戰》 (Hageng's Anti-Tilt Battle)

> **「今天絕對不破防！優雅氣質技術台～」**  
> 一款以 Twitch 知名暴躁氣質實況主**「哈耿」**為主角的情緒管理與極限節奏反應網頁遊戲！

---

## 🎮 遊戲簡介

中央是哈耿的視訊直播框，畫面兩側會源源不絕湧來「粉絲正向讚美」與「黑粉釣魚挑釁」彈幕！  
玩家必須依靠神經反射，在維持優雅營業甜笑的同時，光速敲槌 BAN 掉各種嘴砲挑釁。  
一旦漏掉釣魚彈幕，哈耿的破防量表將會狂飆，甚至觸發扯耳機、拍桌、暴怒飆口頭禪，滿 100% 更會直接拔網路線關台，本月圖奇收益瞬間歸零！

---

## ✨ 遊戲特色

* 🌸 **極致封面詐欺**：開場偽裝成粉嫩治癒系戀愛小品《哈耿的精緻日常》，點擊開台瞬間黑膠刮盤卡死、重低音暴震，無縫變身狂暴戰場！
* 🥁 **雙風格自研音樂引擎**：
  * **開始畫面**：清脆可愛的日系鋼片琴／八音盒童謠旋律。
  * **戰鬥實況**：140 BPM 狂暴 Trap 節奏、過載破音 808 狂暴滑音貝斯與急促警報音。
* 🎯 **動態雙向舒適判定**：
  * 拋棄單邊綁定誤區，彈幕無論從左或右來，按愛心即炸出粉紅光環、按鐵鎚即砸下爆裂重擊！
  * 文字框寬度舒適判定，精準進圈給予 `PERFECT!! 🔥` 評級。
* 📈 **隨時間狂飆的動態難度**：彈幕速度從 260px/s 線性飆升至 680px/s，後期觸發左右雙向同時夾擊！
* ⚙️ **實況主後台全自訂系統**：
  * **封面美照**：支援上傳自選仙女網美照。
  * **情緒表情包**：支援上傳替換 4 個情緒階段（優雅、抽搐喝水、暴怒扯耳機、拔線倒台）的照片／GIF。
  * **口頭禪語音原聲**：內建 3 首經典語音槽（*「去你媽的！」*、*「踢爆你的骨灰罈！」*、*「到底是在靠杯三小啊！」*），支援上傳真實錄音剪輯。
  * **背景音樂**：支援玩家自選 MP3/WAV 上傳循環播放。
* 🏆 **實況抗壓名人堂**：局後記錄最高積分、存活時間與連擊數，支援本地 LocalStorage 排行榜。
* 📱 **全平台極致適配**：電腦鍵盤、手機雙拇指觸控、直橫屏零延遲響應。

## 🕹️ 操作說明

| 操作按鍵 (電腦) | 手機觸控 | 動作 | 對應彈幕與效果 |
| :--- | :--- | :--- | :--- |
| **`J`** / **`Z`** / **`←`** | **左側粉紅大按鈕** | **手比愛心 / 營業甜笑** | 消除**粉紅正向彈幕**（茶爸、倒立哥等），破防值 -5%！<br>*(⚠️ 誤對黑粉假笑：破防 +15%)* |
| **`K`** / **`X`** / **`→`** | **右側紅色大按鈕** | **BAN掉 / 桌咚反擊** | 敲除**鮮紅挑釁彈幕**（小火藥、骨灰罈等），強力桌咚！<br>*(⚠️ 誤 BAN 乾爹：破防 +5%)* |

> ⚠️ **失敗條件**：漏掉釣魚彈幕破防狂飆 +20%，破防量表達到 100% 立即拔線關台！

## 🛠️ 技術架構

* **前端架構**：原生純 HTML5、CSS3、Vanilla JavaScript（無任何外部框架或依賴，單檔即可離線運行）。
* **音效與音樂**：Web Audio API 程序化即時合成（無須外部音檔庫）。
* **資料持久化**：Web LocalStorage API（自訂表情包、語音檔 Base64 快取與本地天梯榜）。
